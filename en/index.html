How I work

Briefing

I set the task

A goal in plain words: what is needed and how to check it is done. The director agent breaks it into stages, and each stage into tasks for specific agents.

Review

I check

A task ends in a pull request. Developers’ work is checked by a reviewer with a clean context and by gates: tests, build, types, and screenshots where there is an interface. Decisions on look and features are mine.

Money

I count the cost

Tasks, agents and days have spending caps, and every model call is recorded. On the paid API key the ledger matched the bill to within 1.3%; most work runs on a subscription, where cost is counted at API prices. Routine goes to cheaper models, review and architecture to stronger ones.
