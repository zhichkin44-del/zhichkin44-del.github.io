How it works

Passwords live in a single encrypted file on your computer. The key is derived from the master password with Argon2id, and the data is encrypted with AES-256-GCM. The app is forbidden from using the network, the clipboard clears after 15 seconds, and the vault locks itself.

  1. Master password
  2. Argon2id64 MiB, 3 passes
  3. Keyin memory only
  4. AES-256-GCM
  5. Vault fileplus a backup copy

What it looks like

Honestly: Forget the master password and nothing can be recovered — by design. There has been no external audit. The installer was built locally; building it from the open code with GitHub Actions is the next step.
