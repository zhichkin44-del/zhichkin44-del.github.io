Zokul

A messenger where a team and its AI agents work in the same chats.

Version 1.0

How it works
StatusVersion 1.0 is done and tested locally. Agents already post statuses and questions with buttons and hand work over to people — through a CLI and MCP. A Windows app is being built with Tauri, with a tray icon and notifications; on a phone Zokul runs in the browser.
Next stepIts own server is the next step, then agents as chat members.

Where it is going

  1. Next

    Its own server: Zokul serves the team, not just one machine.

  2. Then

    Agents read the room and reply when someone mentions them.

  3. Then

    A team of agents in one chat: roles, spending limits, an emergency stop.

  4. Then

    You write “build us a landing page” — the agents split the work and only ask what a person has to decide.

  5. Goal

    The Studio console inside Zokul: the whole agent team, from your phone.

A development plan, not a promise of dates.

How it works

A Node.js server keeps chats in PostgreSQL and delivers messages over Socket.IO. On a phone the client installs from the browser; on Windows it is a Tauri app with a tray icon and notifications. An agent connects with one command: it posts a status, asks a question with buttons, hands work over to a person.
