Secretary

Finds remote openings and prepares an application

A Pulse AI module: collects openings from ten open sources, scores each one and prepares an application with no made-up numbers.

A module of the Pulse AI console

How it works
StatusRuns inside Pulse AI. Collects remote openings from hh.ru, Habr Career, open Telegram channels and global feeds — no logins, no bypassing protection. Scores each by role, stack and freshness and explains why it fits and what is missing.
Next stepAnalysis of which applications worked.

Where it is going

  1. Next

    An application pack as one card: letter, slides, site link — review and send from the phone.

  2. Then

    Letter variants per type of role, and a review of which applications worked.

  3. Goal

    A secretary for any job seeker: their own profile, their own sources, honest letters with no invented numbers.

A development plan, not a promise of dates.

How it works

The radar reads RSS feeds, open APIs and public Telegram channel pages, filters out what does not fit and scores the rest. The letter is built only from checked phrases: a number that is not on the fact sheet will not pass the check. I send it myself; there is no mass mailing.

  1. Open feedshh, Habr, Telegram, global
  2. Filter and scorerole, stack, risks
  3. Application packletter, slides, site
  4. Letter checkapproved facts only
  5. I send itby hand

Honestly: The public hh API rejects requests without authorisation (checked with our own request on 4 November 2026), so the radar reads the official search RSS feed: at most 20 latest openings per query. If a site asks “are you a robot”, reading stops — the check is never bypassed.
