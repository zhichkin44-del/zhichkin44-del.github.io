Next stepThe “AI” channel charter, a function map and reference drafts of 10 formats.

Where it is going

  1. Next

    Any channel in an evening: set the topic and tone — the engine picks sources and starts publishing.

  2. Then

    A network of channels on one engine, each with its own profile and audience.

  3. Then

    Control from the console and Zokul: approve a post, change the topic, stop publishing — one tap on the phone.

  4. Goal

    Round-the-clock operation on a server with no human involved.

A development plan, not a promise of dates.

How it works

A radar reads about a hundred sources; selection follows the topic profile with quotas and duplicate merging; an AI editor writes the post, gates check it, then comes the card and publication.

  1. Radar~100 sources
  2. Selectionquotas, duplicates
  3. AI editorthe post
  4. Gateschecks
  5. Publishingthe card
