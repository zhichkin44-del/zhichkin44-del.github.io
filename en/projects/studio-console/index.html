Pulse AI

An AI agent team I run from my phone

A console: one strong model commands the agents, the agents run the projects, I make the decisions from my phone.

Runs every day

How it works
StatusIn use every day. I write the goal in the chat — then the system lays the work out across projects, checks it and merges it. Only decisions come to me: money, releases, access — as a card on my phone.

What is inside

Secretary

Finds remote openings in ten open sources, scores each by role and stack and prepares an application. I send it myself.

Video Studio console

Episodes, a frame board and a decision on every frame. The judge returns weak frames with a breakdown — only finished ones reach me.

News studio

A radar reads about a hundred sources, an editorial team of agents prepares posts, checks decide what goes out.

Review and permissions

A separate agent checks every piece of work against scenarios — nothing gets into main without its “accepted”. Risky actions go through a permission layer: no answer means no.

How it is built

The operator is Opus: one strong model holds the goal and hands out work. Every project has its own lead agent on Sonnet. Haiku does the routine. The result of any task is a pull request, checked by a reviewer with a clean context and by automated checks — tests, build, screenshots. Every model call is logged; tasks, agents and days have spending caps.
