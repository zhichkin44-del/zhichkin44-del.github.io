Что внутри

Секретарь

Ищет удалённые вакансии в десяти открытых источниках, оценивает каждую по роли и стеку и готовит отклик. Отправляю я сам.

Пульт Видеостудии

Эпизоды, доска кадров и решение по каждому кадру. Слабые кадры судья возвращает с разбором — до меня доходят готовые.

Новостная студия

Радар читает около сотни источников, редакция из агентов готовит посты, проверки решают, что выходит.

Контроль и разрешения

Отдельный агент проверяет каждую работу по сценариям — без его «принято» в main ничего не попадает. Опасные действия идут через слой разрешений: нет ответа — значит отказ.

Как устроено

I set a goal. The director agent breaks it into stages and tasks. Tasks go to agents on laptops; the result is a pull request. Developers’ work is checked by a reviewer with a clean context and by gates: tests, build, types, and screenshots where there is an interface. The console records the cost of every model call and keeps caps per task, agent and day.
