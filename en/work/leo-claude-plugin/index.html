A Claude Code plugin that remembers decisions and checks the final answer

Restores decisions and promises after context compaction, and has a second model act as a skeptic before the final report.

Automation

Message me on TelegramAll work
The taskAfter context compaction, a long Claude Code session loses the thread: it forgets the owner's decisions and what was promised. It needed a way to bring that context back and to double-check the final report.
PricePrice: on request, after a short brief

What was built

  • A SessionStart hook (on compact and resume) puts a summary back into context: working windows, decisions waiting for the owner, the day's rules.
  • A Stop hook runs Claude Haiku as a skeptic on final answers. It looks for unverified claims and missed promises; a serious finding blocks the answer with a reason.
  • The Haiku call is isolated: no tools, a single turn, a timeout.
  • New rules from the owner's messages are never written automatically: the plugin only prompts the lead, and the decision stays with the owner. No trigger words are hard-coded.
  • Changes from the skeptic's own review are included.

Test run

How it works

  1. A SessionStart hook restores decisions and promises after compaction.
  2. A Stop hook sends the final answer to a tool-free, single-turn Haiku skeptic with a timeout.
  3. A serious finding blocks the answer and shows the reason.
  4. Everything runs on Node.js with no external dependencies.
  • Node.js (ESM)
  • Claude Code hooks
  • Claude Haiku
  • node:test

What you get

  • A Claude Code plugin with the two hooks, set up for your workflow.
  • Tests for hook behaviour, safe failures and timeouts.
