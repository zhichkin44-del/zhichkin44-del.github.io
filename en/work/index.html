How I work

I don't write code by hand. I set the task, define the rules and sign off on the result. AI writes the code, and checker agents that I configure for each project review it.

  • The task and the rules are mine: what the result must be, how we know it is done, and what is off limits.
  • The main model writes the code. Only a separate checker with its own role can correct it: a tester, an editor, or a "client" who is as picky as you are.
  • Nothing reaches you until the checker says "done": tests, a pass through every screen, a check against the task.
  • My attention goes to the task and the quality, not the syntax. That makes it faster, with fewer rounds of fixes.
