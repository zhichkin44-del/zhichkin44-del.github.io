Offline password manager for Windows

Encrypted vault for passwords, keys and notes. No cloud, no account, no network access at all.

The taskPasswords scattered in a browser, notes or on paper are unsafe. Cloud password managers keep them on someone else's server and need an account. People want a tool where everything is encrypted and stays with them.
PricePrice: on request, after a short brief

What was built

  • Encryption: AES-256-GCM (a modified file simply will not open), with the key derived from the master password by Argon2id (64 MiB memory, 3 passes).
  • No network at all: no sync, no telemetry, no update checks.
  • Entries: passwords, protected notes, custom fields.
  • Auto-lock after inactivity (5 minutes by default); Ctrl+L locks at once.
  • Careful saving through a temporary file, with the previous version kept as a backup.

Screens

How it works

  1. Create a vault with a master password.
  2. Add entries; search with Ctrl+K and copy with one click.
  3. The vault locks itself after inactivity.
  4. Export an encrypted backup whenever you like.
  • Tauri 2
  • Rust
  • TypeScript
  • Vite

What you get

  • Installing Vault for you or adapting it: your own entry types, name and look, language.
  • Or a similar vault for your task (team secrets, keys, licences).
  • An installer and a portable version.
