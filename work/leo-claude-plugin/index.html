Плагин для Claude Code, который помнит решения и проверяет итоговый ответ

Долгая сессия Claude не забывает решения владельца после сжатия памяти, а итоговый ответ перед отправкой проверяет вторая, независимая модель.

Автоматизация

ЗадачаКогда долгая сессия Claude Code сжимает память, она теряет нить: забывает решения владельца и что было обещано. Нужно было возвращать этот контекст и перепроверять итоговый отчёт до того, как его увидит человек.
ЦенаПо брифу

Что сделано

  • После сжатия памяти или перезапуска плагин сам возвращает сводку: какие задачи в работе, какие решения ждут владельца, правила дня.
  • Перед итоговым ответом его читает вторая модель — Claude Haiku. Она ищет непроверенные утверждения и забытые обещания; если находка серьёзная, ответ останавливается с объяснением.
  • Проверяющая модель работает отдельно: ничего не может менять, отвечает за один ход и с ограничением по времени.
  • Новые правила из сообщений владельца плагин не записывает сам: он только подсказывает, а решение остаётся за владельцем.

Как работает

  1. Сессия сжала память — плагин возвращает решения и обещания.
  2. Модель готовит итоговый ответ.
  3. Вторая модель проверяет его: факты, обещания, пропуски.
  4. Серьёзная находка — ответ останавливается и показывает причину.
  5. Всё работает на Node.js без внешних зависимостей.
  • Node.js (ESM)
  • Claude Code hooks
  • Claude Haiku
  • Встроенные тесты Node.js

Что вы получите

  • Плагин Claude Code под ваш рабочий процесс: память решений и проверка ответов второй моделью.
  • Автоматические тесты: что плагин делает при сбоях и задержках.
