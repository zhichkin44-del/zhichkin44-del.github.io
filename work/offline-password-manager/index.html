Offline password manager for Windows

Encrypted vault for passwords, keys and notes. No cloud, no account, no network access at all.

Problem

Passwords scattered in a browser, notes or on paper are unsafe. Cloud password managers keep them on someone else's server and need an account. People want a tool where everything is encrypted and stays with them.

What I built

  • Encryption: AES-256-GCM (a modified file simply will not open), with the key derived from the master password by Argon2id (64 MiB memory, 3 passes).
  • No network at all: no sync, no telemetry, no update checks.
  • Entries: passwords, protected notes, custom fields.
  • Auto-lock after inactivity (5 minutes by default); Ctrl+L locks at once.
  • Careful saving through a temporary file, with the previous version kept as a backup.
