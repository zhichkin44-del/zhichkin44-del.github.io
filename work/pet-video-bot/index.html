Telegram-бот, который ведёт по ежедневной съёмке ролика о питомце

Ведёт человека без технического опыта по ежедневным заданиям съёмки, сам монтирует вертикальный ролик и пишет текст поста для каждой площадки.

Боты · Автоматизация

Написать в TelegramВсе работы
ЗадачаЧеловеку без технического опыта нужно регулярно снимать ролик о питомце и публиковать его на нескольких площадках. Бот ведёт и монтирует, а публикует человек сам.
ЦенаПо брифу

Что сделано

  • Сценарий заданий: задания первой и второй недели, видео и ответы принимаются прямо в чате.
  • Автоматический монтаж: вертикальный ролик 18 секунд с выровненной громкостью, как требуют площадки.
  • Тексты постов для каждой площадки и проверка качества ролика перед отправкой.
  • Бот не падает, если где-то ещё запущена его прежняя версия.

Как работает

  1. Бот выдаёт задание дня и принимает видео.
  2. Сам собирает вертикальный ролик 18 секунд с выровненной громкостью.
  3. Проверка качества ловит проблемы до отправки ролика.
  4. Бот пишет текст поста для каждой площадки; публикуете вы сами.
  • Node.js 20+
  • Telegram Bot API
  • ffmpeg
  • Встроенные тесты Node.js

Что вы получите

  • Бот с пошаговым сценарием заданий под ваш случай.
  • Автоматический монтаж роликов с проверкой качества.
  • Тексты постов для каждой площадки.
