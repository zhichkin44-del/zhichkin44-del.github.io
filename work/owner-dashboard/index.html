Owner dashboard: projects, tasks and one-tap decisions

One screen for every project: what is moving, what is stuck and what waits for your decision.

Problem

Several projects, assistants on different computers, and ten windows to open to see where things stand. People want one place.

What I built

  • A home screen showing what waits for the owner, answered with a button.
  • Projects, stages, tasks and statuses.
  • Handing out tasks to assistants on different computers.
  • A gate before hand-over: a stage counts as done only after its checks pass.
  • Spend tracking, a knowledge base and a project showcase in the same dashboard.
