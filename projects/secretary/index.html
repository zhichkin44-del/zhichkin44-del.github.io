Секретарь

Находит удалённые вакансии и готовит отклик

Модуль Pulse AI: собирает вакансии из десяти открытых источников, оценивает каждую и готовит отклик без выдуманных цифр.

Модуль пульта Pulse AI

Как это работает
СостояниеРаботает внутри Pulse AI. Собирает удалённые вакансии из hh.ru, Хабр Карьеры, открытых Telegram-каналов и мировых лент — без входа и обхода защиты. Оценивает каждую по роли, стеку и свежести и объясняет: почему подходит и чего не хватает.
Следующий шагРазбор, какие отклики сработали.

Куда идёт

  1. Следующий этап

    Пакет отклика одной карточкой: письмо, слайды, ссылка на сайт — проверить и отправить с телефона.

  2. Затем

    Варианты письма под тип вакансии и разбор, какие отклики сработали.

  3. Цель

    Секретарь для любого соискателя: свой профиль, свои источники, честные письма без выдуманных цифр.

План развития, не обещание сроков.

Как это работает

Радар читает RSS-ленты, открытые API и публичные страницы Telegram-каналов, отсеивает неподходящее и оценивает остальное. Письмо собирается только из проверенных фраз: цифру, которой нет в листе фактов, проверка не пропустит. Отправляю сам; массовой рассылки нет.

  1. Открытые лентыhh, Хабр, Telegram, мир
  2. Отбор и оценкароль, стек, риски
  3. Пакет откликаписьмо, слайды, сайт
  4. Проверка письматолько утверждённые факты
  5. Отправляю самруками

Честно: Публичный API hh отвечает отказом на запросы без авторизации (проверено нашим запросом 4 ноября 2026), поэтому радар читает официальную RSS-ленту поиска: не больше 20 последних вакансий на запрос. Если площадка спрашивает «вы не робот», чтение останавливается — обходить проверку нельзя.
