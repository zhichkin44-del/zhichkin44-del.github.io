Секретарь

Собирает вакансии из открытых источников и готовит пакет отклика: письмо, слайды, сайт.

Модуль пульта Pulse AI

Как это работает
СостояниеРаботает внутри пульта. Собирает удалённые вакансии из hh.ru, hh.kz, Хабр Карьеры, открытых Telegram-каналов и мировых лент (Hacker News, Remote OK, We Work Remotely, Remotive) — через открытые ленты, API и публичные страницы каналов, без входа и обхода защиты. Оценивает каждую вакансию по роли, стеку, свежести и рискам и готовит пакет отклика.
Следующий шагПакет отклика под конкретную вакансию: письмо, слайды и ссылка на сайт — одной карточкой на телефоне.

Куда идёт

  1. Следующий этап

    Пакет отклика одной карточкой: письмо, слайды, ссылка на сайт — проверить и отправить с телефона.

  2. Затем

    Варианты письма под тип вакансии и разбор, какие отклики сработали.

  3. Цель

    Секретарь для любого соискателя: свой профиль, свои источники, честные письма без выдуманных цифр.

План развития, не обещание сроков.

Как это работает

Радар читает RSS-ленты и открытые API площадок и публичные страницы Telegram-каналов, отсеивает неподходящее и оценивает остальное от 0 до 100. Письмо к вакансии собирается только из утверждённых фраз: проверка не пропускает цифру, которой нет в листе фактов. Письмо открыто называет ИИ-помощника: «дальше на связи мой ИИ-помощник, решения принимаю я». Отправляю сам: на hh и Хабре — руками, автоматической рассылки нет.

  1. Открытые лентыhh, Хабр, Telegram, мир
  2. Отбор и оценкароль, стек, риски
  3. Пакет откликаписьмо, слайды, сайт
  4. Проверка письматолько утверждённые факты
  5. Отправляю самруками

Как это выглядит в Пульсе

Честно: Публичный API hh отвечает отказом на запросы без авторизации (проверено нашим запросом 4 ноября 2026), поэтому радар читает официальную RSS-ленту поиска: не больше 20 последних вакансий на запрос. Если площадка спрашивает «вы не робот», чтение останавливается — обходить проверку нельзя.
