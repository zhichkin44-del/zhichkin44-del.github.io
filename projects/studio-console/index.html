Pulse AI

Команда ИИ-агентов, которой я управляю с телефона

Пульт: одна сильная модель командует агентами, агенты ведут проекты, я принимаю решения с телефона.

Работает каждый день

Как это работает
СостояниеРаботает каждый день. Я пишу цель в чат — дальше система сама раскладывает работу по проектам, проверяет и сливает. Ко мне приходят только решения: деньги, выкладка, доступы — карточкой на телефон.

Что внутри

Секретарь

Ищет удалённые вакансии в десяти открытых источниках, оценивает каждую по роли и стеку и готовит отклик. Отправляю я сам.

Пульт Видеостудии

Эпизоды, доска кадров и решение по каждому кадру. Слабые кадры судья возвращает с разбором — до меня доходят готовые.

Новостная студия

Радар читает около сотни источников, редакция из агентов готовит посты, проверки решают, что выходит.

Контроль и разрешения

Отдельный агент проверяет каждую работу по сценариям — без его «принято» в main ничего не попадает. Опасные действия идут через слой разрешений: нет ответа — значит отказ.

Как устроено

Оператор — Opus: одна сильная модель держит цель и раздаёт работу. У каждого проекта свой ведущий агент на Sonnet. Рутину делает Haiku. Результат любой задачи — pull request: его проверяют контролёр с чистым контекстом и автоматические проверки — тесты, сборка, снимки экранов. Расход каждого вызова модели записан, у задачи, агента и дня есть потолок.
