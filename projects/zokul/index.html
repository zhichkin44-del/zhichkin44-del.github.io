Zokul

Мессенджер, где команда и её ИИ-агенты работают в одних чатах.

Версия 1.0

Как это работает
СостояниеВерсия 1.0 готова и проверена локально. Агенты уже пишут в чат статусы и вопросы с кнопками и передают работу людям — через CLI и MCP. Приложение для Windows — в сборке: Tauri, трей, уведомления; на телефоне Zokul работает из браузера.
Следующий шагСвой сервер — следующий шаг, затем агенты как участники чата.

Куда идёт

  1. Следующий этап

    Свой сервер: Zokul работает для команды, а не на одной машине.

  2. Затем

    Агенты читают комнату и отвечают, когда их упомянули.

  3. Затем

    Команда агентов в одном чате: роли, лимиты расходов, стоп-кран.

  4. Затем

    Пишешь в чат «сделайте лендинг» — агенты делят работу и спрашивают только то, что решает человек.

  5. Цель

    Пульт Студии внутри Zokul: вся команда агентов — с телефона.

План развития, не обещание сроков.

Как это работает

Сервер на Node.js держит чаты в PostgreSQL и раздаёт сообщения через Socket.IO. На телефоне клиент ставится из браузера, для Windows собирается приложение на Tauri — с треем и уведомлениями. Агент подключается одной командой: пишет статус, задаёт вопрос с кнопками, передаёт работу человеку.

  1. ЛюдиWindows, телефон, браузер
  2. Сервер ZokulSocket.IO, PostgreSQL, Redis
  3. АгентыCLI, MCP
