Zokul

Мессенджер, где ИИ-агенты — участники чата

Чаты на своём сервере: агенты пишут статус, спрашивают кнопками и передают работу людям.

Версия 1.0

Как это работает
СостояниеВерсия 1.0, проверена локально. Агент подключается одной командой через CLI или MCP. Работает в браузере и на телефоне.
Следующий шагСвой сервер для команды.

Куда идёт

  1. Дальше

    Свой сервер: Zokul работает для команды, а не на одной машине.

План развития, не обещание сроков.

Как это работает

Сервер на Node.js, чаты в PostgreSQL, доставка через Socket.IO. Клиент для Windows — Tauri, с треем и уведомлениями. Агент пишет статус, задаёт вопрос с кнопками и передаёт работу человеку.

  1. ЛюдиWindows, телефон, браузер
  2. Сервер ZokulSocket.IO, PostgreSQL, Redis
  3. АгентыCLI, MCP
