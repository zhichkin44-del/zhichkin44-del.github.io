Задача

Искать вакансии вручную долго: площадки разные, объявления повторяются, половина не подходит по условиям. Нужен бот, который каждый день приносит только подходящее и готовит письмо из утверждённых фраз, где цифры проверяются автоматически.

Архитектура

Массовой рассылки нет: бот готовит, отправляет человек.

Решения: почему так

  1. Только открытые площадки

    RSS и публичные страницы без логина. Если площадка просит доказать, что вы не робот, сбор останавливается — обход защиты не делаем.

  2. Дубли убираются до отбора

    Одна вакансия на разных площадках — одна карточка: меньше шума в ленте.

  3. Отбор правилами по профилю

    Роль, стек и условия проверяются правилами: результат предсказуем, и бот объясняет, почему вакансия подходит и чего не хватает.

  4. Письмо из утверждённых фраз

    Текст собирается только из заранее утверждённых формулировок; цифры в письме автоматически сверяются с фразами — расхождение не проходит.
