AI bots and automation · Video shooting and editing bot

A Telegram bot that guides daily pet-video shooting

Leads a non-technical person through daily shooting tasks, assembles a vertical clip with ffmpeg and writes the post text for each platform.

84tests pass15 Nov 2026
Open source: GitHubMessage me on Telegram

The task

A person with no technical background needs to shoot a video about a pet regularly and publish it on several platforms. The bot does the guiding and the editing; the person publishes.

What was built

  1. A task script: first-week and second-week tasks, with videos and answers received in the chat.

  2. An ffmpeg edit: vertical format, an 18-second clip at about -14 LUFS (the loudness level video platforms expect).

  3. Post texts for each platform, and a quality check of the clip before it is sent.

  4. A safeguard so a second copy of the bot running by mistake does not break it.

How it works

  1. The bot gives the day's task and receives the video.
  2. ffmpeg assembles a vertical 18-second clip at about -14 LUFS (the loudness level video platforms expect).
  3. A quality check catches problems before the clip is sent.
  4. The bot writes a post text per platform; you publish it yourself.

Stack

  • Node.js 20+
  • Telegram Bot API
  • ffmpeg
  • Node.js built-in tests

Code

The code is open on GitHub: read it, run the tests, check it.
