Офлайн-менеджер паролей для Windows

Зашифрованное хранилище для паролей, ключей и заметок. Без облака, без аккаунта и без доступа к сети.

Задача

Пароли, разбросанные по браузеру, заметкам или бумаге, небезопасны. Облачные менеджеры паролей хранят их на чужом сервере и требуют аккаунт. Людям нужен инструмент, где всё зашифровано и остаётся у них.

Что сделано

  1. Шифрование: AES-256-GCM (изменённый файл просто не откроется), ключ выводится из мастер-пароля по Argon2id (64 МиБ памяти, 3 прохода) — это замедляет подбор пароля перебором.

  2. Никакой сети: нет синхронизации, телеметрии и проверки обновлений.

  3. Записи: пароли, защищённые заметки, пользовательские поля.

  4. Автоблокировка после бездействия (по умолчанию 5 минут); Ctrl+L блокирует сразу.

  5. Бережное сохранение через временный файл: предыдущая версия остаётся как резервная копия.

Как работает

  1. Создайте хранилище с мастер-паролем.
  2. Добавляйте записи, ищите через Ctrl+K и копируйте пароль одним нажатием.
  3. Хранилище блокирует себя после бездействия.
  4. Экспортируйте зашифрованную резервную копию, когда захотите.
