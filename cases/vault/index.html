Case studies / Vault — an offline password manager

Open source · Vault — an offline password manager

Offline password manager for Windows

Encrypted vault for passwords, keys and notes. No cloud, no account, no network access at all.

63tests pass14 Nov 2026
Open source: GitHubMessage me on Telegram

The task

Passwords scattered in a browser, notes or on paper are unsafe. Cloud password managers keep them on someone else's server and need an account. People want a tool where everything is encrypted and stays with them.

What was built

  1. Encryption: AES-256-GCM (a modified file simply will not open), with the key derived from the master password by Argon2id (64 MiB memory, 3 passes) — this slows down password-guessing attacks.

  2. No network at all: no sync, no telemetry, no update checks.

  3. Entries: passwords, protected notes, custom fields.

  4. Auto-lock after inactivity (5 minutes by default); Ctrl+L locks at once.

  5. Careful saving through a temporary file, with the previous version kept as a backup.

How it works

  1. Create a vault with a master password.
  2. Add entries; search with Ctrl+K and copy with one click.
  3. The vault locks itself after inactivity.
  4. Export an encrypted backup whenever you like.
