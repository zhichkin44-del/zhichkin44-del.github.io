The task

An English-language channel about documented but unexplained events. It needs a consistent visual style, visible primary sources and a repeatable path to an episode.

What was built

  1. A series bible (approved 27 Sep 2026): the series, illustration style, editing rules.

  2. A topic queue with primary sources for every fact.

  3. Episodes: Kokoro voice-over, frames via ComfyUI, ffmpeg assembly, an upload package with chapters and covers.

  4. Case Shorts in three formats on a shared builder — about 50 seconds each.

  5. In episode 002 the check found black frames — they never reached the upload; episode 003 passed the technical checks.

How it works

  1. A topic from the queue — with primary sources.
  2. Script and Kokoro voice-over.
  3. Frames in ComfyUI in the series style.
  4. ffmpeg assembly and checks of the finished file.
  5. Shorts from the same components.
